# Концептуализатор ХХХ

Локальное веб-приложение для визуализации концептуальных карт и связей между узлами.

## 🚀 Как использовать

1. Откройте файл `conceptualizer.html` в любом современном браузере (Chrome, Firefox, Edge, Safari)
2. Начните создавать узлы и связи между ними
3. Все изменения автоматически сохраняются в браузере

## ✨ Основные функции

### Создание узлов
- **Базовый процесс** (круг) - с категориями (внимание, когниция, эмоции и т.д.)
- **Часть/Субличность** (квадрат)
- **Интегративный процесс** (шестиугольник)

### Создание связей
- **Активирует** - зелёная стрелка
- **Подавляет** - красная стрелка
- **Поддерживает** - синяя стрелка
- **Противоречит** - оранжевая стрелка
- Настраиваемая сила связи (1-5)

### Навигация по холсту
- **Зум**: колесо мыши (зум относительно курсора)
- **Панорамирование**:
  - Зажмите **пробел** + перетаскивание мышью
  - ИЛИ правая кнопка мыши + перетаскивание
- **Перемещение узла**: левая кнопка мыши + drag
- **Редактирование узла**: двойной клик

### Сохранение и загрузка

#### 💾 Автосохранение
- Все изменения автоматически сохраняются в браузере (localStorage)
- При повторном открытии файла ваша работа восстанавливается
- Сохраняются: узлы, связи, позиция камеры, уровень зума

#### 💾 Сохранить файл
- Кнопка "💾 Сохранить файл" - скачивает JSON файл на компьютер
- Формат имени: `concept_YYYY-MM-DD_timestamp.json`
- Файл содержит всю информацию о вашей карте

#### ⬆ Загрузить файл
- Кнопка "⬆ Загрузить файл" - импортирует ранее сохранённый JSON
- Восстанавливает все узлы, связи и позицию камеры

#### ⬇ Показать JSON
- Показывает JSON в текстовом поле для копирования

## 🎨 Цветовая кодировка категорий

- **Внимание** - голубой
- **Когниция** - красный
- **Эмоции** - жёлтый
- **Селфинг** - салатовый
- **Поведение** - оранжевый
- **Мотивация** - фиолетовый
- **Биофизиология** - бирюзовый
- **Ситуация** - светло-зелёный
- **История** - розовый
- **Социум** - розово-персиковый
- **Терапия** - светло-фиолетовый

## 🔧 Технические детали

- Полностью автономное приложение
- Не требует интернет-соединения
- Не требует установки
- Работает локально в браузере
- Данные хранятся только на вашем компьютере

1. **Психотерапия**: визуализация схем и паттернов мышления
2. **Концептуальное моделирование**: связи между понятиями
3. **Планирование**: зависимости между задачами
4. **Обучение**: карты знаний и понятий
