# Концептуализатор ХХХ

Локальное веб-приложение для визуализации концептуальных карт и связей между узлами.

## 📦 Установка и запуск

### Вариант 1: Скачать как ZIP архив (рекомендуется)

1. Перейдите на страницу репозитория на GitHub
2. Нажмите кнопку **"Code"** → **"Download ZIP"**
3. Распакуйте архив в любую папку на вашем компьютере
4. Откройте файл `conceptualizer.html` в любом современном браузере
5. Готово! Приложение запущено и готово к работе

### Вариант 2: Клонировать через Git

Если у вас установлен Git:

```bash
git clone https://github.com/ваш-username/concept.git
cd concept
```

Затем просто откройте файл `conceptualizer.html` в браузере.

### Требования

- **Браузер**: любой современный браузер (Chrome, Firefox, Edge, Safari, Opera)
- **Интернет**: не требуется (только для первоначальной загрузки шрифтов при первом запуске)
- **Установка**: не требуется - это один HTML файл

## 🚀 Быстрый старт

1. Откройте файл `conceptualizer.html` в браузере (можно просто дважды кликнуть на файл)
2. Начните создавать узлы и связи между ними
3. Все изменения автоматически сохраняются в браузере (localStorage)

## ✨ Основные функции

### Создание узлов
- **Базовый процесс** (круг) - с категориями (внимание, когниция, эмоции и т.д.)
- **Часть/Субличность** (квадрат)
- **Интегративный процесс** (шестиугольник)

### Создание связей
- **Активирует** - зелёная стрелка
- **Подавляет** - красная стрелка
- **Поддерживает** - синяя стрелка
- **Противоречит** - оранжевая стрелка
- Настраиваемая сила связи (1-5)

### Навигация по холсту
- **Зум**: колесо мыши (зум относительно курсора)
- **Панорамирование**:
  - Перетащите **пустое место** левой кнопкой мыши (как в Miro)
  - ИЛИ зажмите **пробел** + перетаскивание мышью
  - ИЛИ средняя кнопка мыши (колесо)
  - ИЛИ правая кнопка мыши + перетаскивание
- **Перемещение узла**: перетащите узел левой кнопкой мыши
- **Редактирование узла**: двойной клик

### Сохранение и загрузка

#### 💾 Автосохранение
- Все изменения автоматически сохраняются в браузере (localStorage)
- При повторном открытии файла ваша работа восстанавливается
- Сохраняются: узлы, связи, позиция камеры, уровень зума

#### 💾 Сохранить файл
- Кнопка "💾 Сохранить файл" - скачивает JSON файл на компьютер
- Формат имени: `concept_YYYY-MM-DD_timestamp.json`
- Файл содержит всю информацию о вашей карте

#### ⬆ Загрузить файл
- Кнопка "⬆ Загрузить файл" - импортирует ранее сохранённый JSON
- Восстанавливает все узлы, связи и позицию камеры

#### ⬇ Показать JSON
- Показывает JSON в текстовом поле для копирования

## ❓ Часто задаваемые вопросы

**Q: Нужен ли мне интернет для работы приложения?**  
A: Нет, после первой загрузки приложение работает полностью офлайн. Интернет нужен только для первоначальной загрузки шрифтов.

**Q: Где хранятся мои данные?**  
A: Данные хранятся локально в браузере (localStorage). Для резервного копирования используйте кнопку "💾 Сохранить файл".

**Q: Можно ли использовать на нескольких компьютерах?**  
A: Да, но данные не синхронизируются автоматически. Используйте экспорт/импорт JSON файлов для переноса данных.

**Q: Работает ли на мобильных устройствах?**  
A: Приложение можно открыть на мобильных устройствах, но интерфейс оптимизирован для работы с мышью и клавиатурой. Лучше использовать на десктопе.

**Q: Нужен ли мне веб-сервер?**  
A: Нет, просто откройте HTML файл напрямую в браузере. Никакой сервер не требуется.
